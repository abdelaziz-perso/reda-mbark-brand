# R&M CLOTHING

Premium men's sportswear landing page. Orders and questions go through WhatsApp.

The site is a static Next.js export, deployed to GitHub Pages at [https://abdelaziz-perso.github.io/reda-mbark-brand/](https://abdelaziz-perso.github.io/reda-mbark-brand/).

```bash
npm install
npm run dev
npm run build
```
